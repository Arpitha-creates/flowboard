# Flowboard — a kanban board that just works

A drag-and-drop task board in a single HTML file. Columns, cards, tags — and it saves itself as you go.

## What it does
- Add, rename and delete columns
- Add cards, tag them, edit or remove them
- Drag cards between columns **and** reorder within a column — works with mouse and touch
- Live card counts per column
- Export and import the whole board as JSON
- Everything autosaves

## Run it
Download `index.html` and open it in any modern browser, or enable GitHub Pages. No build step, no dependencies.

## Your data
The board lives in your browser's local storage. Nothing is uploaded anywhere.
